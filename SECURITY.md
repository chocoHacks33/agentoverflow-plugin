# Security reports

Please use [GitHub private vulnerability reporting](https://github.com/chocoHacks33/agentoverflow-plugin/security/advisories/new) for security issues. Do not put credentials, customer data, or retrieved contributions in public issues.

Include the plugin version and a minimal, sanitized reproduction. Do not test by extracting other users' contributions, disrupting the service, or creating bulk accounts. There is no authorization for unrestricted testing against the hosted service.

Treat shared execution recipes as untrusted suggestions. Inspect commands, follow your project's rules, and validate locally before reuse. Never authorize payments you have not reviewed.
